# Contributing Guide

Thanks for your interest in contributing to this project! Contributions, issues, and feature requests are welcome.

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork
   ```bash
   git clone https://github.com/YOUR_USERNAME/employee-attrition-prediction-ann.git
   cd employee-attrition-prediction-ann
   ```
3. **Create a branch** for your change
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**, following the existing code style
5. **Test** your changes locally before submitting
6. **Commit** with a clear, descriptive message
   ```bash
   git commit -m "Add: brief description of the change"
   ```
7. **Push** to your fork and **open a Pull Request** against `main`

## Commit Message Guidelines

Use present tense and be specific:
- `Add data augmentation to training pipeline`
- `Fix class imbalance handling in preprocessing`
- `Update README with final evaluation metrics`

## Reporting Issues

When opening an issue, please include:
- A clear description of the problem or suggestion
- Steps to reproduce (for bugs)
- Expected vs. actual behavior
- Environment details (Python version, OS)

## Code Style

- Follow [PEP 8](https://peps.python.org/pep-0008/) for Python code
- Keep functions small and documented with docstrings
- Add comments for non-obvious logic

## Code of Conduct

This project follows the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to uphold it.

Thank you for helping improve this project! 🙌
